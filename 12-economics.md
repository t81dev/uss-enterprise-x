# 12 — Economics

## Cost is a design variable

A starship that can technically be built but cannot be produced repeatedly is strategically equivalent to a prototype.

Economic analysis therefore tracks:

- cost per structural kilogram;
- cost per installed kilowatt;
- cost per radiator area;
- labor hours per vehicle;
- inspection and rework burden;
- refurbishment cost;
- launch and propellant cost;
- fleet utilization.

A sub-billion-dollar hull target may be used as an aspirational scenario, but it is not treated as credible until the mass, production rate, supply chain, test campaign, and launch architecture support it.

## Scale

The program should pursue a production system capable of learning from every vehicle. Fleet size is not merely an operational metric; it is a source of reliability data and manufacturing improvement.
