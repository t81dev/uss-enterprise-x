# 08 — Crew Interface

## Minimalist bridge hypothesis

The bridge should be smaller, quieter, and more information-dense than the traditional Enterprise bridge.

Replace large numbers of switches and decorative stations with:

- a small number of redundant displays;
- physical emergency controls for critical functions;
- configurable software panels;
- panoramic or synthetic situational visualization;
- distributed control so one workstation failure does not disable the ship.

## Neural interface branch

A direct neural-control interface is retained as an experimental branch inspired by the concept of future brain-computer interfaces.

It must **not** be treated as mandatory bridge infrastructure until safety, reliability, cybersecurity, training, and reversibility are demonstrated.

The first-generation Enterprise should remain fully operable without an invasive neural interface.
